# 雑学動画 台本ルール（1本＝1テーマ）

毎日1本、約3分の「〇〇の雑学10選」動画（〇〇はその日のテーマ）の台本 `scripts/<日付>.json` を書くときの規約。
見本は `scripts/trial_01.json`（文体・構成・書式はこれに合わせる。内容は流用しない）。

## テーマ（1本＝1テーマ）

**1本の動画は、その日のテーマ1つだけで10個そろえる。** その日のテーマは台帳が決める
（`python3 zatsugaku_state.py theme` で表示される。担当を取ったときの `THEME:` 行と同じ）。
自分でテーマを選ばない・変えない。

テーマは次の28個を毎日1つずつ順に回す（28日で一巡。順番と範囲の正典は `zatsugaku_state.py` の THEME_SCOPE）：
筋トレ → 恋愛 → 栄養 → 婚活 → プロテイン → 幸福感 → ビタミン → 夫婦生活 → ダイエット → 暮らし →
がんと生活習慣 → 女性が好む男性 → アンチエイジング → 人生 → 筋肥大 → 推し活 → 美容 → 投資 →
病気予防 → ネットで攻撃する人 → 認知症予防 → 資産管理 → 健康情報 → 男性が好む女性 → 結婚しない人生 →
睡眠 → 顔出し発信する専門家 → 世代別の男女

テーマ名は画面と題名に出す短い呼び名。**扱う範囲は `python3 zatsugaku_state.py theme --scope` が出す説明に従う**
（例：「夫婦生活」の範囲は「夫婦生活のメリット・デメリット」。メリットとデメリットの両方を扱う）。

- 台本の最上位に `"theme": "<その日のテーマ>"` を書く。10個すべての `category` もそのテーマにする。
- 10個はテーマの中で切り口を散らす（例：筋トレなら、高齢者・女性・回数・頻度・睡眠との関係・
  よくある思い込み、など。同じ研究や同じ結論の言い換えを並べない）。
- 筋トレと筋肥大、栄養とプロテイン・ビタミンのように近いテーマは、過去回と話題が重なりやすい。
  `state.json` の used_topics を必ず見て、言い換えただけの重複も避ける。

### 10個そろわないとき（テーマを切り替える）

今日のテーマで、過去回と重ならず、出典で確かめられた雑学が10個そろわないときは、**作り話で埋めず、テーマを切り替える。**

- コマンドを実行できる場合（クラウド）：`python3 zatsugaku_state.py skip-theme` を実行し、表示された新しい THEME と範囲で
  台本を最初から書き直す（`theme` と各 `category` も新しいテーマにする）。
- コマンドを実行できない場合（Mac）：台本の代わりに `scripts/<日付>.skip` に、そろわなかった理由を1〜2行で書いて終わる。
  あとはスクリプトがテーマを切り替えて、書き直しを頼み直す。

### 人を扱うテーマの注意（婚活・夫婦生活・結婚しない人生・推し活・ネットで攻撃する人・女性が好む男性・男性が好む女性・顔出し発信する専門家・世代別の男女）

- **調査の数字として伝え、決めつけない。** 「〇〇な人は△△だ」ではなく「〇〇の調査では、△△と答えた人が□%でした」。
  世代や性別の傾向を扱うときは、必ず「個人差は大きい」ことを1本のどこかで言う。
- 出典は、国立社会保障・人口問題研究所（出生動向基本調査）・内閣府・総務省・こども家庭庁などの公的調査か、
  心理学・社会学の査読論文。**民間企業のアンケートやマッチングアプリの調査は使わない。**
- **病名や障害名で人をくくらない。** 「精神」「心理」を扱うときも、診断のような言い方
  （「〇〇障害の人が多い」「病んでいる」）をしない。研究で測った性格の傾向や動機として伝える。
- 特定の性別・世代・結婚している人／していない人・推し活をする人を、からかう・見下す言い方をしない。
  メリットとデメリットを扱うテーマは、両方を同じくらいの重みで出す。
- ネットで攻撃する人のテーマは、攻撃のやり方や相手の特定方法など、まねできる手口を説明しない。
  受けた側の相談先は、公的な窓口（総務省の違法・有害情報相談センターなど）だけを紹介する。
- 「顔出し発信する専門家」のように研究が少ないテーマは、近い研究（専門家の情報発信と信頼、
  顔を出すことの効果、自己開示の心理など）まで広げてよい。**それでも10個そろわないときに作り話で埋めない。**
  確かめられた範囲で10個に届かなければ、下の「10個そろわないとき」に従ってテーマを切り替える。

### 睡眠の注意

- 睡眠時間の重要性・健康への影響に加えて、話題の「自称ショートスリーパー」が本当はどうなのかを必ず1〜2個入れる。
  - 睡眠を削り続けた実験で、本人の眠気の自覚と実際の成績（注意力など）がずれていく研究を一次資料で伝える。
  - 遺伝子の変異で本当に短い睡眠で足りる人がごくまれにいることも、研究どおりに伝える（ゼロとは言わない）。
  - 特定の人物・発信者・番組を名指ししない、からかわない。「自分はショートスリーパーだと思っている人の多くは〜」のように研究の結果として伝える。
- 睡眠薬やサプリなど特定の商品・治療を勧めない。眠れない悩みは医療機関への相談を勧めるにとどめる。

### がんと生活習慣の注意

- 出典は、国立がん研究センターの「科学的根拠に基づくがん予防」や、国際がん研究機関の評価、査読論文。
- 「〇〇を食べるとがんになる／ならない」と言い切らない。「リスクが△%高かった」「関連が確実と評価されている」のように、
  評価の強さ（確実・ほぼ確実・可能性あり）をそのまま伝える。
- 特定の食品・サプリ・治療法を勧めない。検診は、国が勧めるがん検診として紹介するのにとどめる。

### 暮らしの分野の注意

- 恋愛・幸福感・人生は、心理学や社会学の査読論文か、内閣府・総務省などの公的調査を出典にする。
  **再現に失敗した有名な心理学実験**（パワーポーズ、自我消耗、吊り橋効果など）は使わない。
  扱うなら「のちの追試では再現されなかった」と必ず言う。
- 投資・資産管理は、**一般的な事実と制度の紹介に限る**。出典は金融庁・日本銀行・総務省の統計・
  国税庁などの公的資料か、査読論文。
  - 特定の銘柄・投資信託・金融商品・証券会社を勧めない。「買うべき」「必ず増える」「損しない」と言わない。
  - 将来の利回りを約束する言い方をしない。過去の数値は「過去の〜では」と時期を明示する。
  - 保険・ファイナンシャルプランナー相談・マネーセミナーには触れない（勧めない・紹介しない）。
  - 制度（新NISA・iDeCo の非課税枠や上限額など）は、**動画を作る日時点の公式ページで確かめた値**を使い、
    「2026年10月時点」のように時点を言う。

## 出典（最重要）

- **10個すべてに、確認できる一次資料をつける。** 査読論文（Europe PMC で要旨を読めるもの）か、
  厚生労働省・国立研究機関などの公的資料に限る。テレビ・まとめ記事・個人ブログは出典にしない。
- **数値は、実際に要旨や資料を読んで確かめたものだけを使う。** 記憶で書かない。
  論文は `https://www.ebi.ac.uk/europepmc/webservices/rest/search?format=json&resultType=core&query=EXT_ID:<PMID>`
  を WebFetch で開き、要旨の数値と照合する（pubmed.ncbi.nlm.nih.gov はボット判定で読めないので使わない）。
- 主張の強さを変えない。観察研究の結果を「〜すると防げる」と言い切らない（「〜の人ほど低かった」）。
  効果がはっきりしなかったものは「はっきりしなかった」と書く。
- 少人数の実験は人数を言う（「12人の実験では」）。
- 根拠の弱い俗説・語源説は扱わない。扱うなら「〜と言われています」と明示する。
- 薬機法に触れる言い方をしない（「治る」「効く」「若返る」は使わない）。**問いかけの形（「〇〇に効く？」）でも使わない。**
  「よい？」「役立つ？」「関係ある？」のように言い換える。
- **題名（youtube.title）でも主張の強さを変えない。** 観察研究の結果を「〇〇で死亡率13%減」と言い切らず、
  「〇〇好きは死亡リスク13%低い」のように書く。
- **`state.json` の `used_sources` にある出典と `used_topics` にある話題は使わない（重複禁止）。**

## 言葉づかい

- 英語の略語を使わない（RCT・BMI・LDL・HIIT などは日本語に開く。「悪玉コレステロール」など）。
  例外は制度の正式名称の「NISA」「iDeCo」だけ（読み上げは「ニーサ」「イデコ」と書く）。
- 翻訳調を避け、自然な話し言葉で書く。「〜です」「〜ます」で結ぶ。
- 筋肉は「育つ」ではなく「発達する」、「重い重さ」ではなく「高重量」と書く（題名も同じ）。
- 研究者向けの用語（メタ解析・コホート・エビデンス・バイアス）を画面の文字に出さない。
  読み上げでも「〜の研究をまとめた分析」のように言い換える。
- 雑誌名は日本語で書く（JAMA→米国医師会雑誌、Lancet→ランセット、BMJ→英国医師会雑誌、
  NEJM→ニューイングランド医学誌、PNAS→米国科学アカデミー紀要、Cochrane→コクラン・レビュー）。

## 構成と分量

- items の先頭は導入（画像 `hirameki_man`）、最後は締め（画像 `uroko_man`）。中身はちょうど10個。
  導入の1行目は「知って得する\n〇〇の雑学」、読み上げは「知って得する、〇〇の雑学。」（〇〇はテーマ名）。
- 並び順は、意外性の強いものを最初と最後に置く。
- 1個の雑学は 3〜4 行。1行目は問いかけか結論、2〜3行目で研究の中身、最後に数値か一言。
- `caption`（画面の文字）は1行14字以内×最大2行。改行は `\n`。数字と記号（%・kg）はそのまま。
- `say`（読み上げ）は1文60字以内。数字の読み間違いを避けるため、人数は「12人の若い男性」のように
  数字のあとに名詞がくっつかない順に書く（「男性12人」は「男性じゅう、ふたり」と誤読される）。
- **読み上げの合計は 1,150〜1,350 字。** これで約3分になる。
- 締めの3行は見本と同じ（いくつ知っていましたか／出典は概要欄に／チャンネル登録）。

## 絵（いらすとや）

- 各雑学に `image_query` を1つ書く。いらすとやで検索してヒットしそうな**具体的な名詞1〜2語**
  （例：「握力計」「プロテイン」「万歩計」「補聴器」「マラソン」）。
  `image_query_alt` に第2候補も書く。人物は内容に合う年代・性別を選ぶ語にする（「筋トレ お爺さん」）。
- 導入と締めは `image` に `hirameki_man.png` / `uroko_man.png` を直接書く（`image_query` 不要）。

## 出力形式

```json
{
  "theme": "筋トレ",
  "title": "画面用タイトル",
  "speaker": 13,
  "gemini_voice": "Charon",
  "items": [
    {"image": "hirameki_man.png", "lines": [{"caption": "…", "say": "…"}]},
    {"image_query": "握力計", "image_query_alt": "握力", "topic": "握力と死亡リスク", "category": "筋トレ",
     "source": "Leong ほか（2015年・ランセット）", "pmid": "25982160",
     "lines": [{"caption": "…", "say": "…"}]}
  ],
  "youtube": {
    "title": "（40字以内。例：9割が知らない筋トレの雑学10選【論文で確認済み】＋その回の目玉を一言）",
    "description": "1〜2行の紹介文",
    "tags": ["雑学", "<テーマ>", "…"],
    "sources": ["著者 ほか. 雑誌名 年;巻:頁 https://europepmc.org/article/MED/<PMID>", "…"]
  }
}
```

公的資料の場合は `pmid` の代わりに `"url": "https://..."` を書く。
