## 1. 再生リストを2つに分ける

今ある再生リストは52個です。そのうち公開は3個（「汚れた英雄」「MIAMI VAICE Sound Track」「エクササイズ」）で、どれも田園生活の動画のまとめではありません。チャンネルのページに出るのはこの3個です。

| 新しい再生リスト | 入れる動画 | 説明文の案 |
|---|---|---|
| 猫と旅の一言シリーズ | 手撮りの動画（猫・沖縄・横浜・東京湾・秩父など） | 旅先やわが家で出会った子たちの、ひと言つきの短い動画です。新しい子に会うたびに足していきます。 |
| 9割が知らない体づくりの雑学 | 雑学動画（「9割が知らない〜」） | 筋トレ・栄養・体づくりの「本当はどうなの？」を、論文で確かめて約3分で紹介します。 |

- 記事の動画は、続けることになった場合だけ、3つ目の再生リスト「田園生活の記事から」にまとめます。
- 公開の3個（個人のお気に入り）を非公開にするかどうかは、オーナーが決めてください。チャンネルのページが田園生活の動画だけになり、初めて来た人に何のチャンネルか伝わりやすくなります。
- チャンネルのページの「おすすめ」の欄に「猫と旅の一言シリーズ」を一番上に置くのは、YouTube Studio の画面からの操作です（オーナーの作業）。

「沖縄の残波岬が縄張りですがなにか?」（1FG4q3GzM-A）など、再生が1,000回を超えた手撮りの動画の概要欄の一番上に、次の文を足します。

## 3. 固定コメント（案）

固定コメントは、YouTube の決まりで、外からの仕組みでは固定できません。オーナーが YouTube Studio かスマホのアプリで、コメントを書いて「固定」を押してください。

**手撮り動画用**
```
ここ、わたしの縄張りです🐾 ほかの場所の子たちにも会えます → 猫と旅の一言シリーズ（再生リストのアドレス）
```

**雑学動画用**
```
ほかの「9割が知らない」もどうぞ → 9割が知らない体づくりの雑学（再生リストのアドレス）
いちばん意外だったのは何番でしたか？
```

## 4. 必要な許可の追加（題名・概要欄・再生リストの変更用）

今の許可でできるのは「動画を上げる」「一覧を見る」だけです。題名・概要欄の変更と再生リストの作成には、「YouTube アカウントの表示、編集、完全削除」の許可が必要です。

- この許可は範囲が広く、動画の削除もできる強さです。仕組みは削除の操作を一切使わず、題名・概要欄・再生リストの変更だけに使います。
- 手順は今日の許可の取り直しと同じです。こちらで許可用のアドレスを出すので、ブラウザで開き、すべてのチェックを入れて「続行」を押してください。最後に開けない画面になったら、アドレス欄の中身を全部コピーして貼り付けてください。
- 許可が取れたら、題名は1回に30本までに分けて変えます（`yt_manage.py titles`）。再生リストは `yt_manage.py playlist` で作ります。どちらも、まず変更内容の一覧をお見せして、了承をいただいてから実行します。
