# 雑学動画のテーマの絞り込み（2026-10-11 決定・反映済み）

> **決定**: オーナーが5テーマ案を了承し、あわせて次の方針を指示した。
> - 筋トレは毎回、体の部位を1つに絞る（脚・お尻・背中・胸・肩・腕・お腹・ふくらはぎを順に回す）
> - 筋トレだけでなく、持久系・健康維持・長寿につながる内容も作る
> - 筋トレで体の中に起こる良い変化も扱う
> - 週1回、既存の動画をふりかえる10分以上の動画を作る（日曜・`cloud/weekly_review.sh`）
>
> 反映後のテーマ（8つ）: 筋トレ（部位別）→ 栄養 → 持久力 → プロテイン → 筋肥大 → 健康長寿 → 筋トレで変わる体 → ビタミン。

## 案：筋トレ・栄養・体づくりの5テーマに絞る

| 順番 | テーマ | テーマの範囲（台本を書くときの指示） |
|---|---|---|
| 1 | 筋トレ | 筋トレのやり方・回数・頻度・休み方・年代別の注意 |
| 2 | 栄養 | 体づくりのための食事・食べる時間・食材 |
| 3 | 筋肥大 | 筋肉が発達する仕組み・高重量と軽い重さ・回復と睡眠 |
| 4 | プロテイン | たんぱく質の量・とり方・食品との違い |
| 5 | ビタミン | ビタミン・ミネラルの不足と取りすぎ、サプリの研究 |

- **外すテーマ**：上の5つ以外の23テーマ（恋愛・婚活・幸福感・夫婦生活・推し活・ネットで攻撃する人・投資・資産管理など）。
- **順番の工夫**：1日2本なので、「筋トレ＋栄養」「筋肥大＋プロテイン」「ビタミン＋筋トレ」…と組み合わさります。似ている筋トレと筋肥大が同じ日にならない並びにしました。
- **切り替えたときの続き**：台帳で最後に順番どおり投稿したテーマのうち、新しい一覧にあるのは「筋肥大」（10/9の2本目）です。そのため、切り替えた翌日は「プロテイン」から始まります。台帳の theme_overrides（10/3〜10/5の筋トレ固定）は過去の日付だけで、筋トレも残すので、ぶつかりません。
- **別の案**：再生が約100回あった「暮らし」「人生」のどちらかを6つ目に残すこともできます。体づくりからは外れますが、ネタ切れのときの逃げ道にもなります。

## ネタ切れのときにテーマを飛ばす仕組み（skip-theme）の確認と懸念

**今の動き**

- 1本目：台本を書く人（Mac の Claude かクラウド）が「確かめられた別のネタが10個そろわない」と判断すると、skip-theme を実行します。その日のテーマを台帳の theme_skips に記録し、順番で次のテーマに替えます。
- 2本目：extra-prepare に外すテーマを渡して、次のテーマに替えます。
- 過去の回とかぶっていないかは、話題の文字列がまったく同じかどうかと、論文の番号（出典の番号）が同じかどうかでしか調べていません。

**5テーマに絞ったときの懸念**

1. **ネタ切れが早い。** 1日2本なので、1つのテーマが2〜3日ごとに回ってきます。10日で約40個の新しい雑学が要る計算です。筋トレ・筋肥大は特に重なりやすいテーマです。
2. **言い方を変えた同じ話を見逃す。** かぶりの検査は文字列が同じかどうかだけです。同じ事実を別の論文や別の言い方で出すと、すり抜けます。テーマが少ないと、この危険が大きくなります。
3. **飛ばしたことを覚えていない。** 飛ばした記録はその日限りです。ネタが尽きたテーマも2〜3日後にまた回ってきて、毎回調べ直してから飛ばすことになり、作る時間が無駄になります。
4. **全部飛ばすと、その日は1本も出ない。** 5つとも飛ばすと「使えるテーマが残っていません」で止まります。クラウドの予備も同じ台帳を使うので、代わりに作れません。

**対策の案（了承をいただければ、テーマの変更と一緒に入れます）**

- 飛ばしたテーマは、14日間休ませる（台帳に、休ませる期限の日付を残す）。
- 全部のテーマが使えない日は、予備のテーマ（例：暮らし）で作る。
- 過去の回の話題の一覧（同じテーマの分）を台本を書く人に渡して、言い方を変えた同じ話を避けるよう指示文に書き足す。
