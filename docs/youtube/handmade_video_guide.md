# 手撮り動画の手順書（2026-10-11）

チャンネルの再生の9割以上は、オーナーが手で撮った短い動画（猫・沖縄の景色など）です。
1本あたりの再生の中央値は約250回で、当たると約1,000回になります。
これからは手撮りの動画を中心にして、題名の付け方と投稿の時刻をそろえます。

## 1. 題名の型：「場所＋この子の一言」

当たった例:「沖縄の残波岬が縄張りですがなにか?」（2日で1,085回・高評価52）

- 書く順番は **どこで** → **誰が** → **ひと言（その子のせりふ）**
  - 例:「わが家のクロちゃん『ご飯まーだー？』」
  - 例:「沖縄・浜比嘉ビーチの駐車場の子『ここで待ってるね』」
  - 例:「横浜の公園のリス『どんぐり、もらっていい？』」
- 題名は30文字以内にします。スマホの一覧では、後ろの方が切れて見えなくなるためです。
- 日付やサイトのアドレスは**題名に入れない**で、概要欄に書きます。
- 場所は、「沖縄」より「沖縄・残波岬」のように、できるだけ具体的に書きます。地名で探す人に見つけてもらいやすくなります。
- 同じ子が続けて出るときは、名前をいつも同じにします（クロちゃん、など）。

## 2. 概要欄のひな形

```
（場所）で会った（この子）です。（ひと言の続きや、その場の様子を1〜2行）

📍 撮影場所: （場所）／（撮影日）
▶ 猫と旅の一言シリーズ（再生リスト）: （アドレス）
▶ 田園生活のサイト: https://denenseikatu.com/

#猫 #（地名） #田園生活
```

## 3. 投稿の時刻（1日1〜2本・毎日同じ時刻）

| 本数 | 時刻（日本時間） |
|---|---|
| 1本目 | 12:30 |
| 2本目（ある日だけ） | 21:30 |

- 昼（12〜15時）に出した手撮り動画は、中央値が569回で一番高い結果でした。ただ、9本しかないので、はっきりしたことは言えません。夜（18〜24時）は本数が多く、中央値は約200〜270回です。
- 撮った日にすぐ全部出すと、同じ日の動画どうしで再生を取り合います。10月は11日間で65本（1日約6本）出していました。撮りためた分は、YouTube の「公開予約」で次の日以降の決まった時刻に回します。
- 雑学動画（朝7:30ごろと9時台に公開）とは時刻をずらします。

## 4. 投稿のたびの確認

1. 題名は「場所＋この子の一言」の型になっているか。日付やアドレスだけになっていないか。
2. 概要欄に、撮影場所・再生リスト・サイトのアドレスを書いたか。
3. 「猫と旅の一言シリーズ」の再生リストに入れたか。
4. 公開の時刻は 12:30 か 21:30 か（公開予約を使う）。
