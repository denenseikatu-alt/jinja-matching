# 週1回のふりかえり動画（10分以上）の台本ルール

毎週日曜に、その週に投稿した動画の内容をふりかえる、10分以上の動画の台本 `review.json` を書くときの決まり。
2026-10-11 オーナー指示（「週一回は既存動画の内容をレビューするような10分以上の動画も生成する」）。

材料は `review_source.json`（`bash cloud/weekly_review.sh prepare` が作る）。形式・声・語り手は記事動画と同じ
（`prompts/narration.md` の文章・読み・字幕のルールをすべて守る。見本は `talk/40s-safe-aerobic-talking.json`）。

## 中身

- **扱うのは材料にある雑学と記事だけ。** 新しい数字や研究を足さない。数字は材料の `say` と出典のとおりに言う。
- その週の体づくり（筋トレ・栄養・持久力・健康長寿など）の雑学から、**8〜12個を選んで深掘りする**。
  - 再生の多かった回の雑学を厚めにする。
  - 1つの雑学につき2〜3場面を使う。何がわかったか → どんな研究か（人数・期間・どんな人たちか）
    → どこまで言えるか（観察した研究なら「関係がある」までで「原因」とは言わない・個人差・研究の弱いところ）
    → 毎日の暮らしでどう生かすか。
  - 同じ週の雑学どうしのつながりがあれば、つなげて話す（例：たんぱく質の量と筋肥大の回）。
- 記事動画があれば、1〜2場面で「今週の記事から」として要点を紹介する。
- 体づくりと関係の薄いテーマの回（恋愛など）は、無理に入れない。

## 構成

1. 導入（1場面）: 「今週の体づくり雑学ふりかえり」と、今週ふりかえる内容の予告。
2. 本編（深掘り。全体の約8割）。
3. 今週のまとめ（1場面）: 3つにまとめる。
4. 次回の予告と動画の紹介（1場面）: 毎日の「9割が知らない」雑学動画があること。
5. **最後の1場面は田園生活のサイトの紹介**（narration.md「構成」4 と同じ。画面に denenseikatu.com、
   読み上げは「でんえんせいかつドットコム」、caption_replace で字幕を英字に戻す）。

## 分量と形式

- **読み上げの合計は 4,000〜4,800字**（10分〜12分半。Gemini Leda の話す速さは1秒に約6字）。場面は 24〜32。
- 1文は60字以内。bullets は5項目まで。
- 題名（youtube.title）は「今週の体づくり雑学ふりかえり｜」で始め、その週のいちばん意外な話を続ける
  （例：「今週の体づくり雑学ふりかえり｜軽い重さでも筋肉は発達する？ほか10本」）。
  「育つ」ではなく「発達する」、「重い重さ」ではなく「高重量」と書く。
- 概要欄（youtube.description）には、ふりかえった各回の動画の題名とアドレス（材料の url）を並べる。
- `voice` と `youtube` ブロックは見本どおり（public・synthetic true）。`site` は「田園生活」、`site_host` は denenseikatu.com。
  `source_url` は書かない。
